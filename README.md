# ひと筆マージ (ONE STROKE MERGE)

6×6 盤面で同じ数字を一筆書きの要領でつなげて合体させるパズルゲーム。スマホのタッチ操作対応。

## 遊ぶ

https://tpc57439.github.io/hitofude-merge/

## 遊び方

- 上下左右で同じ数字を2つ以上なぞってつなぐと合体して数字が1つ上がります
- 5つ以上つなぐと連鎖ボーナス
- 動かせる手がなくなったらゲームオーバー

単一の `index.html` だけで動く静的サイトです。

# ねこ寿司ループ (`sushi/`)

回転寿司レーンにネタを流して、お客さんの注文をさばくパズルゲーム。

https://tpc57439.github.io/hitofude-merge/sushi/

- 下のトレイをタップすると、いちばん上の寿司が1皿ずつレーンに流れます
- お客さんは注文したネタが目の前を通ると取ってくれます
- レーンがいっぱいで流せなくなったら負け（レーン長押しで早送り）
- レベルは自動生成で無限に続きます（必ず解ける盤面だけを出題）
- タイトルで「かんたん（Lv.1〜）」「むずかしい（Lv.8〜）」「鬼（Lv.15〜）」を選べます
